# The Choice Before the Calculation

## Chapter 8: Why Split at Fifty

Priya had the case file card **48 × 52** and a free choice. The calculation had not started. She could split the numbers in many ways, and the way she picked would decide how hard the rest was.

### Step 1: Two splits, side by side

**Split 1: take 48 apart as 40 + 8.**

```
( 48 × 52 )
redraw  →  ( ( 40 × 52 ) + ( 8 × 52 ) )
```

Both circles are ready, but they are not friendly. 40 × 52 and 8 × 52 are each a small calculation of their own. Priya would probably need to split again before she could pop either one.

**Split 2: take both numbers apart around 50.**

```
( 48 × 52 )
redraw  →  ( ( 50 − 2 ) × ( 50 + 2 ) )
redraw  →  ( ( 50 × 50 ) − ( 2 × 2 ) )
```

Both circles are friendly. 50 × 50 and 2 × 2 can be popped in your head.

Both splits are correct. They give the same answer, 2,496. The choice was about how friendly the pops would be.

### Step 2: What makes a split friendly?

Priya made a short list of what she looks for before she starts.

- **A friendly number near both.** 50 is near 48 and near 52, so both can move to it.
- **Matching distances.** 2 below and 2 above means the pieces will cancel, as you saw in The Work That Vanishes.
- **Pops you can do at once.** 50 × 50 and 2 × 2 need no further splitting.

### Step 3: When there is no number near both

Priya tried **47 × 52**. The two numbers are 5 apart, so the middle is 49 and a half, which is not friendly. There is no whole number with matching distances.

She did not give up. She picked a friendly number near *one* of them.

```
Choice A:  ( 47 × 52 )  →  ( ( 47 × 50 ) + ( 47 × 2 ) )   =  2,350 + 94    =  2,444
Choice B:  ( 47 × 52 )  →  ( ( 50 × 52 ) − ( 3 × 52 ) )   =  2,600 − 156   =  2,444
```

Both routes reach 2,444. Neither has matching distances, so the pieces do not cancel, but each round number makes one of the pops easy.

So the rule is not "always split at fifty". It is: **look for a friendly number near both. If there is none, look for one near either.**

### Step 4: Choosing is part of the trace

Priya writes the reason for her choice in the notebook, next to the first redraw: *"around 50, matching distances."* Later, she can see what she chose and why, and if the pops turn out hard, she can try another split.

### What did we keep?

Write the answers in your notebook.

- **What did every split keep?** (The value, because each was a legal redraw.)
- **What changed with the choice?** (How friendly the later pops were.)

### What makes this trustworthy?

The choice cannot make the answer wrong, because every legal redraw keeps the value. What it changes is cost and the chance of a slip. A good choice is one you can explain: Priya can say *why* 50 was a good place to split.

### Practice

1. Which split is friendlier for **99 × 101**: both numbers around 100, or 99 taken apart as 90 + 9? Find the answer.

2. Find **21 × 19** by splitting around a friendly number. Say which number you chose.

3. Find **63 × 57** by splitting around 60.

4. For **52 × 53**, there is no whole number with matching distances. Pick a split with a friendly number near one of them and find the answer.

5. Priya says, "I chose a bad split, so my answer is wrong." Is she right?

### Answers

1. Around 100 is friendlier: ( 100 × 100 ) − ( 1 × 1 ) = 10,000 − 1 = **9,999**.
2. Around 20: ( 20 × 20 ) − ( 1 × 1 ) = 400 − 1 = **399**.
3. ( 60 × 60 ) − ( 3 × 3 ) = 3,600 − 9 = **3,591**.
4. For example, ( 52 × 50 ) + ( 52 × 3 ) = 2,600 + 156 = **2,756**.
5. No. A bad split costs more work or more chances for a slip, but a correct redraw never changes the value. Her answer is wrong only if she made a slip along the way.
