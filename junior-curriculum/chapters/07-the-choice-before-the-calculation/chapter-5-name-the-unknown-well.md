# The Choice Before the Calculation

## Chapter 5: Name the Unknown Well

Rina's brother Leo is some age, and her cousin Mia is 3 years older. Their ages add up to 21. How old is each?

Rina decided to give the unknown a name before doing anything else.

### Step 1: Name the small one

Let **L** be Leo's age. Then Mia's age is L + 3.

```
( L + ( L + 3 ) )  =  21
```

Rina redraws the circle so that the two L's are together.

```
( L + ( L + 3 ) )
redraw  →  ( ( L + L ) + 3 )
```

The circle is stuck on L, but she knows the total is 21. So ( L + L ) must be 21 − 3.

```
( L + L )  =  ( 21 − 3 )  →  18
```

Two lots of Leo's age make 18, so Leo is **9** and Mia is **12**. Check: 9 + 12 = 21, and 12 is 3 more than 9. ✓

### Step 2: Choosing the name changes the work

Now a different puzzle: three numbers in a row, such as 5, 6, 7, add up to 48. Which three?

Rina could name the smallest, **s**: then the numbers are s, s + 1, s + 2.

```
( s + ( s + 1 ) + ( s + 2 ) )  =  48
```

That works, but there are two extra bits to carry (the +1 and +2).

Or she could name the **middle** one, **m**. Then the numbers are m − 1, m and m + 1.

```
( ( m − 1 ) + m + ( m + 1 ) )
```

Now the −1 and +1 cancel each other out. What is left is three lots of m.

```
( 3 × m )  =  48
```

So m = 48 ÷ 3 = **16**, and the numbers are **15, 16 and 17**. Check: 15 + 16 + 17 = 48. ✓

The answers are the same. But naming the middle made the extra bits vanish by themselves. That is what a good name does.

### Step 3: What makes a name good?

Rina found three habits.

- **Name the thing you want to find**, not some other quantity.
- **Say what the name stands for**, in words: "L is Leo's age," not just "L."
- **Choose the name that makes the other pieces simple.** If the others are all "plus or minus a little", the middle one often works best.

### What did we keep?

Write the answers in your notebook.

- **What did naming the unknown keep?** (The whole problem, in a form we can work on.)
- **What did the choice of name change?** (How many extra bits had to be carried.)

### What makes this trustworthy?

The answer is checked by going back to the words: 9 and 12 are ages, 12 is 3 more than 9, and they add to 21. If any of those fails, the name or the setup was wrong. A good name also makes the setup easy to read, which makes slips easier to see.

### Practice

1. Two numbers add to 30 and differ by 6. Name the smaller one s and find both.

2. Three whole numbers in a row add to 63. Name the middle one and find all three.

3. A pencil costs 5 dollars more than a pen. Together they cost 17 dollars. Name the pen's price p and find both prices.

4. Check your answer to problem 3 against the words.

5. Why is it better to say "L is Leo's age" than just "let L be a number"?

### Answers

1. The numbers are s and s + 6. ( s + ( s + 6 ) ) = 30, so ( s + s ) = 24 and s = 12. The numbers are **12 and 18**.
2. ( 3 × m ) = 63, so m = 21. The numbers are **20, 21 and 22**.
3. ( p + ( p + 5 ) ) = 17, so ( p + p ) = 12 and p = 6. The pen is **6 dollars** and the pencil is **11 dollars**.
4. 6 + 11 = 17, and 11 is 5 more than 6. ✓
5. Saying what L stands for lets you check the answer against the story and tells you which piece to find.
