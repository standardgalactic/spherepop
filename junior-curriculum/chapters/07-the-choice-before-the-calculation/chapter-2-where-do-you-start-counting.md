# The Choice Before the Calculation

## Chapter 2: Where Do You Start Counting?

Rina had measured how many steps she walked to school on four mornings: 47, 38, 52 and 41. She wanted the total number of steps.

She could add them directly. But Rina had a habit of choosing before calculating, so she asked a different question: *is there a number near all four that I can start from?*

### Step 1: Pick a starting number

All four numbers are near 45. Rina decided to start at 45, and for each day write how far it is above or below 45.

| Day | Steps | Compared with 45 |
|---|---|---|
| 1 | 47 | 2 above |
| 2 | 38 | 7 below |
| 3 | 52 | 7 above |
| 4 | 41 | 4 below |

Now the total is four lots of 45, with a few small corrections. Here it is in circles:

```
( 47 + 38 + 52 + 41 )
redraw  →  ( ( 45 + 2 ) + ( 45 − 7 ) + ( 45 + 7 ) + ( 45 − 4 ) )
redraw  →  ( ( 4 × 45 ) + 2 + 7 − 7 − 4 )
```

She grouped the corrections. Above: 2 + 7 = 9. Below: 7 + 4 = 11. The corrections are 9 up and 11 down, which is 2 down overall.

```
( 4 × 45 )  →  180
( 11 − 9 )  →  2
( 180 − 2 )  →  178
```

The total is **178** steps. Check by adding directly: 47 + 38 = 85, 85 + 52 = 137, 137 + 41 = 178. ✓

### Step 2: Does the start change the answer?

Rina tried two other starting points to see.

**Start at 40.** The days compare as 7 above, 2 below, 12 above, 1 above. Above: 7 + 12 + 1 = 20. Below: 2. Net: 18 above.

```
( ( 4 × 40 ) + ( 20 − 2 ) )  →  ( 160 + 18 )  →  178
```

**Start at 100.** Every day is below 100: by 53, 62, 48 and 59. Together that is 53 + 62 + 48 + 59 = 222 below.

```
( ( 4 × 100 ) − 222 )  →  ( 400 − 222 )  →  178
```

All three starts give **178**. The answer does not depend on where Rina starts counting.

### Step 3: But some starts are kinder than others

Starting at 45 left corrections of 2, 7, 7 and 4. Easy. Starting at 40 left 7, 2, 12 and 1. Fine. Starting at 100 left 53, 62, 48 and 59. Those are big numbers to add, and a slip is more likely.

So the choice matters for how hard the work is and how likely you are to slip, but not for the answer. A good starting point is a number that is **close to everything** and **easy to multiply by**. The number 45 was close, and 4 × 45 was easy. A number like 44 would have been close too, but 4 × 44 is less friendly.

### What did we keep?

Write the answers in your notebook.

- **What stayed the same with every start?** (The total, 178.)
- **What changed with the start?** (The size of the corrections, and so how hard the work was.)

### What makes this trustworthy?

The reason is that each redraw keeps the value. A number like 47 is exactly 45 + 2, so writing it that way loses nothing. Any start works for the same reason.

The check is to add the numbers directly, or to try a second start. If two different starts agree, a slip is much less likely, because two different slips rarely land on the same wrong number.

### Practice

1. Add 98 + 103 + 101 + 99 using a start of 100. Show the corrections.

2. Add 52 + 48 + 51 + 49 + 50 using a start of 50.

3. Add 47 + 38 + 52 + 41 using a start of 50. Do you get 178?

4. For 62 + 58 + 61 + 59, which start is kind? Why?

5. Rina says "starting at 1,000 would also work for 47 + 38 + 52 + 41." Is she right? Is it a good choice?

### Answers

1. Corrections: 2 below, 3 above, 1 above, 1 below. Above: 3 + 1 = 4. Below: 2 + 1 = 3. Net 1 above. ( ( 4 × 100 ) + ( 4 − 3 ) ) pops to **401**.
2. Corrections: 2 above, 2 below, 1 above, 1 below, 0. They cancel to 0. ( 5 × 50 ) pops to **250**.
3. Corrections from 50: 3 below, 12 below, 2 above, 9 below. Below: 3 + 12 + 9 = 24. Above: 2. Net 22 below. ( 200 − 22 ) pops to **178**. Yes.
4. A start of **60** is kind, because all four numbers are within 2 of it. ( 4 × 60 ) pops to 240, and the corrections 2 above, 2 below, 1 above, 1 below cancel out. Total **240**.
5. She is right, the answer would still be 178, but it is not a good choice. The corrections would be big (953, 962, 948, 959) and easy to slip on.
