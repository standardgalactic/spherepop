# The Work That Vanishes

## Chapter 6: Corners with Decimals

Ines was cutting ribbon. One piece was 4.8 metres long and she needed a rectangle of cloth 4.8 metres by 5.2 metres.

"4.8 times 5.2," said Ines. "Decimals. Does the missing corner still work?"

### Step 1: The same trick with smaller steps

The two numbers are on either side of 5, each 0.2 away. Ines wrote it the same way she did with whole numbers.

```
( 4.8 × 5.2 )
redraw  →  ( ( 5 − 0.2 ) × ( 5 + 0.2 ) )
redraw  →  ( ( 5 × 5 ) − ( 0.2 × 0.2 ) )
pop  →  ( 25 − 0.04 )
pop  →  24.96
```

The cloth is **24.96** square metres.

The missing corner is 0.2 × 0.2. Two tenths of two tenths is four hundredths, so 0.04. It is small, but it is still the corner, and it is still taken away.

### Step 2: Why decimals behave

A decimal like 4.8 is just 48 tenths. Ines noticed that 4.8 × 5.2 is the whole-number product 48 × 52, but in tenths. And she already knows 48 × 52 = 2,496, from chapter 1.

```
2,496 hundredths  =  24.96
```

(Tenths times tenths gives hundredths.) The same answer, two ways.

### Step 3: More examples

**9.9 × 10.1.** On either side of 10, each 0.1 away.

```
( ( 10 × 10 ) − ( 0.1 × 0.1 ) )  →  ( 100 − 0.01 )  →  99.99
```

**7.5 × 8.5.** On either side of 8, each 0.5 away.

```
( ( 8 × 8 ) − ( 0.5 × 0.5 ) )  →  ( 64 − 0.25 )  →  63.75
```

**0.9 × 1.1.** On either side of 1, each 0.1 away.

```
( ( 1 × 1 ) − ( 0.1 × 0.1 ) )  →  ( 1 − 0.01 )  →  0.99
```

Look at the last one. 0.9 × 1.1 is a little less than 1. The corner explains exactly how much less: 0.01.

### Step 4: A warning about places

The most common slip is the corner. 0.2 × 0.2 is **0.04**, not 0.4 and not 0.004. A good habit is to count the decimal places: one place times one place gives two places.

### What did we keep?

Write the answers in your notebook.

- **What stayed the same when the numbers got decimals?** (The idea: a rectangle is a square with a corner missing.)
- **What changed?** (The corner got smaller, and the decimal places had to be counted.)

### What makes this trustworthy?

The reason is the same as before. The redraw ( 5 − 0.2 ) × ( 5 + 0.2 ) = ( 5 × 5 ) − ( 0.2 × 0.2 ) works for any step, whole or decimal.

The check is the whole-number version in tenths: 48 × 52 = 2,496, and 2,496 hundredths is 24.96. ✓

### Practice

1. Find 3.8 × 4.2.

2. Find 5.9 × 6.1.

3. Find 1.5 × 2.5. (Hint: the middle is 2 and the step is 0.5.)

4. Find 19.8 × 20.2.

5. Check 3.8 × 4.2 by using whole numbers in tenths.

### Answers

1. ( 4 × 4 ) − ( 0.2 × 0.2 ) = 16 − 0.04 = **15.96**.
2. ( 6 × 6 ) − ( 0.1 × 0.1 ) = 36 − 0.01 = **35.99**.
3. ( 2 × 2 ) − ( 0.5 × 0.5 ) = 4 − 0.25 = **3.75**.
4. ( 20 × 20 ) − ( 0.2 × 0.2 ) = 400 − 0.04 = **399.96**.
5. 3.8 is 38 tenths and 4.2 is 42 tenths. 38 × 42 = 1,596, and 1,596 hundredths is 15.96. ✓
