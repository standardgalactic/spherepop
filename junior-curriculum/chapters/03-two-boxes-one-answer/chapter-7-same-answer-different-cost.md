# Two Boxes, One Answer

## Chapter 7: Same Answer, Different Cost

The detective had two boxes that both multiply 7 by a card. She dropped in the card 10.

```
Box M:  7 + 7 + 7 + 7 + 7 + 7 + 7 + 7 + 7 + 7  →  70
Box N:  ( 7 × 10 )  →  70
```

Both give 70. By the answer-only window, they are the same box.

But she opened the cost window, which counts the pops.

### Step 1: Count the pops

Box M adds one seven at a time. To add ten sevens, it does 9 additions.

```
( 7 + 7 )  →  14
( 14 + 7 )  →  21
( 21 + 7 )  →  28
...
( 63 + 7 )  →  70
```

Box N does one multiplication. That is **1 pop**.

Nine pops against one pop. Same answer, very different cost.

### Step 2: Bigger cards, bigger gap

Now drop in the card 1,000.

- Box M adds 7 a thousand times: **999 additions**.
- Box N does ( 7 × 1,000 ) → 7,000: **1 pop**.

Box M's cost grows with the card. Box N's cost stays the same. If a box has to answer a million cards, that difference matters a great deal.

### Step 3: Windows again

This is the same idea as chapter 4: whether two boxes are the same depends on the window.

- **Answer-only window:** M and N are the same.
- **Pops window:** M and N are different. They popped different circles.
- **Cost window:** M and N are very different. One is cheap and the other grows.

A shopper at the till only needs the answer, but a shop that serves thousands of customers cares about the cost. There is no single right window. The right one depends on what you need.

### Step 4: Same cost does not mean same box

The reverse also holds. Two boxes can cost the same and still be different boxes.

```
Box P:  ( n + n )
Box Q:  ( n × n )
```

Each takes one pop. But at card 5, Box P gives 10 and Box Q gives 25. Equal cost, different answers.

So "same answer" and "same cost" are two different questions. A pair of boxes can match on one, on both, or on neither.

### What did we keep?

Write the answers in your notebook.

- **What did M and N keep in common?** (The answer, for every card.)
- **What did the cost window show?** (A difference the answer-only window could not.)

### What makes this trustworthy?

A claim about boxes is trustworthy when it names the window. "M and N are the same" is true in the answer window. "M and N are equally good" is false in the cost window. If someone says two things are the same, ask: the same in what way?

### Practice

1. Box M adds 7 twelve times. How many additions is that? What does Box N do instead?

2. Box R adds 1 to a card, ten times in a row. Box S adds 10 once. Do they give the same answer? Count the pops.

3. Box P gives ( n + n ) and Box Q gives ( n × 2 ). Do they agree on every card? What is their cost?

4. Which window would a shopper at a till use? Which would a shop owner use?

5. Box T takes 1 pop and Box U takes 1 pop but they disagree at card 5. What does that show about cost and answers?

### Answers

1. Twelve sevens take **11 additions**. Box N does ( 7 × 12 ) → 84, which is **1 pop**.
2. Yes, both add 10 to the card. Box R takes **10 pops** and Box S takes **1 pop**.
3. Yes, they agree on every card, because n + n is two lots of n. Each takes 1 pop.
4. A shopper uses the answer-only window. A shop owner also wants the cost window.
5. Equal cost does not mean equal answers. The boxes are different even though they cost the same.
