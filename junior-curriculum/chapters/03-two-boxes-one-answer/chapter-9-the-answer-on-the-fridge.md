# Two Boxes, One Answer

## Chapter 9: The Answer on the Fridge

Lena's class was making three identical quilts. Each quilt had 48 rows with 52 squares in each row. The question on the card was: **how many squares in all three quilts?**

Two boxes were given the same job.

### Step 1: The first box does everything again

The first box wrote the sum, and then worked out each quilt from the beginning.

```
( ( 48 × 52 ) + ( 48 × 52 ) + ( 48 × 52 ) )
```

For each quilt, it used the missing-corner trace from the case file. Each one took five lines: two redraws and three pops.

```
redraw  →  ( ( 50 − 2 ) × ( 50 + 2 ) )
redraw  →  ( ( 50 × 50 ) − ( 2 × 2 ) )
pop ( 50 × 50 )  →  2,500
pop ( 2 × 2 )  →  4
pop ( 2,500 − 4 )  →  2,496
```

Three quilts is 15 lines. Then it needed two more pops to add the three answers: ( 2,496 + 2,496 ) and then ( 4,992 + 2,496 ). The total is 17 lines and the answer is **7,488**.

### Step 2: The second box writes a note

The second box noticed that the three circles were exactly the same circle. They would all give the same value. So it did the work **once**, and wrote the answer on a sticky note on the fridge.

```
pop ( 48 × 52 )  →  2,496      (five lines of work, then a note)
reuse note  →  2,496
reuse note  →  2,496
pop ( 2,496 + 2,496 )  →  4,992
pop ( 4,992 + 2,496 )  →  7,488
```

The first circle took the usual five lines. A **reuse** is a pop whose answer comes from the notebook instead of from fresh work. The trace still gets a line for it, so a reader can see where the value came from. That is 5 + 2 + 2 = 9 lines.

Both boxes give **7,488**. The second box took 9 lines, and the first took 17.

### Step 3: When the note is safe to use

A sticky note only helps if the circles really are the same. Lena checked a different job: one quilt of 48 × 52 and one of 48 × 53.

```
( 48 × 52 )  and  ( 48 × 53 )
```

These are different circles. The note that says 2,496 belongs to 48 × 52 only. Using it for 48 × 53 would be a wrong reuse. The second one is 2,544, as you saw in The Work That Vanishes.

What about **52 × 48**? It is a different way of writing the same product, so the note applies. Lena knows this because the order of the two numbers does not change a product. She writes why on the note.

### Step 4: What the note costs

Reuse is not free. Someone has to write the note, keep it, and check that the circle matches. For three quilts, the saving is big. For a circle you only need once, a note costs more than it saves.

### What did we keep?

Write the answers in your notebook.

- **What did the second box keep?** (The same answer, 7,488.)
- **What did it change?** (How much work it did: 9 lines instead of 17.)

### What makes this trustworthy?

The second box is trustworthy because its note is checked, not assumed. The reuse is allowed only when the two circles are exactly the same, and the reason is written down. Both boxes get the same answer, so a reader can compare their traces and see where the saving came from.

### Practice

1. How many lines would the first box take for **four** quilts of 48 × 52, if each quilt takes 5 lines and each addition is one pop? How many for the second box?

2. For each pair, say whether one note can serve both: (a) 48 × 52 and 52 × 48, (b) 48 × 52 and 49 × 51, (c) 50 × 50 and 50 × 50.

3. Lena needs 49 × 51 twice. Use the corner trick once, write the note, and find the total.

4. A note says 2,496. Someone wants to use it for 48 × 52 + 1. Is that a reuse of the note? What do they still have to do?

5. A circle will be used only one time. Should the second box bother with a note? Why?

### Answers

1. First box: 4 × 5 = 20 lines for the quilts, plus 3 pops to add four answers: **23** lines. Second box: 5 lines for the first quilt, 3 reuses, and 3 additions: **11** lines.
2. (a) Yes, since the order of a product does not matter. (b) No, they are different circles: 2,496 and 2,499. (c) Yes, they are the same circle.
3. 49 × 51 = 2,500 − 1 = 2,499. Using it twice, 2,499 + 2,499 = **4,998**.
4. The note covers only the 48 × 52 part. They still have to add the 1: 2,496 + 1 = **2,497**.
5. No. A note costs effort to write and check, and a circle used once gets nothing back.
