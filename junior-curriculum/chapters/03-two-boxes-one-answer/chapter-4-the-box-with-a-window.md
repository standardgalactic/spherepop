# Two Boxes, One Answer

## Chapter 4: The Box With a Window

Here are two new boxes, Box E and Box F. You drop in a card, and a number slides out. Both boxes give **12**, every time.

Box E is built to pop the circle ( 3 × 4 ). Box F is built to pop the circle ( 2 × 6 ).

### Step 1: Same answer, from outside

From the slot, you only see the 12. So by the detective's rule from chapter 1, you cannot tell Box E from Box F. They agree on everything you can see.

```
Box E:  ( 3 × 4 )  →  12
Box F:  ( 2 × 6 )  →  12
```

Now someone cuts a small window in each box. Through the window you can see the notebook, which is the trace of pops. Box E shows a line: *pop ( 3 × 4 ) → 12.* Box F shows: *pop ( 2 × 6 ) → 12.*

With the window, the boxes are different at a glance. Nothing about their answers changed. What changed is **what you are able to see**.

### Step 2: Which differences can you see?

Here are two more boxes.

**Box G** always pops the left circle first. **Box H** always pops the right circle first. Both are given the same problem:

```
( ( 2 + 3 ) × ( 4 + 1 ) )
```

Here is what each box writes in its window.

```
Box G                                  Box H
pop ( 2 + 3 )  →  5                    pop ( 4 + 1 )  →  5
pop ( 4 + 1 )  →  5                    pop ( 2 + 3 )  →  5
pop ( 5 × 5 )  →  25                   pop ( 5 × 5 )  →  25
```

Look through three different windows.

- **The answer-only window.** It shows just 25. The boxes look the same.
- **The pops window.** It shows which circles were popped, as a collection. Both boxes popped the same three circles, so the boxes look the same.
- **The order window.** It shows which circle was popped first. Now Box G and Box H are different.

So whether two boxes are the same depends on which window you have. The same two boxes can be identical through one window and different through another.

### Step 3: Choose the window for the job

Which window is the right one? It depends on who is asking.

A shopper only cares how much she pays. For her, the answer-only window is enough, and two boxes that give the same price are the same.

A cook cares about the recipe. For him, ( 3 × 4 ) and ( 2 × 6 ) are different, even if both give 12, because they mean different amounts of different things.

A teacher checking homework cares about the order of steps, so the order window matters to her.

There is no single correct window. But there is a correct way to talk: **before you say two boxes are the same, say who is watching and what they can see.**

### What did we keep?

Write the answers in your notebook.

- **What stayed the same when we added a window?** (The answers. Nothing changed inside the boxes.)
- **What changed?** (What the watcher could see, and therefore which boxes counted as the same.)

### What makes this trustworthy?

The reason from chapter 1 still holds, but it now has a limit. Redrawing ( n + n ) as ( n × 2 ) keeps the *value*, so for someone who only sees values, the boxes are always the same. For someone with a pops window, the redraw is a visible change, and the boxes are not the same.

So a statement like "these boxes are the same" is only complete when it names the window. Without that, it is missing a part.

### Practice

1. Box J pops ( 6 + 6 ). Box K pops ( 4 + 8 ). Do they look the same through the answer-only window? Through the pops window?

2. Box L pops ( ( 1 + 2 ) + ( 3 + 4 ) ) left circle first. Box M pops it right circle first. Which window tells them apart? What number does each box give?

3. Box N pops ( n + 0 ). Box P pops ( n × 1 ). For every n, do they look the same through the answer-only window? Through the pops window?

4. Name one job where the answer-only window is enough, and one job where you would want to see the pops.

5. ( 2 × 6 ) and ( 12 × 1 ) both pop to 12. Which window would you need to tell the boxes apart?

### Answers

1. Through the answer-only window, both show 12, so they look the same. Through the pops window they differ: one popped ( 6 + 6 ) and the other popped ( 4 + 8 ).
2. The **order window** tells them apart. Both boxes give **10**, since ( 1 + 2 ) is 3, ( 3 + 4 ) is 7, and 3 + 7 is 10.
3. Through the answer-only window they look the same for every n, because adding 0 and multiplying by 1 both give back n. Through the pops window they are different, because one box adds and the other multiplies.
4. Many answers work. For example: checking the price on a bill needs only the answer. Checking someone's homework wants the pops.
5. The pops window. Box ( 2 × 6 ) pops that circle and box ( 12 × 1 ) pops a different one.
