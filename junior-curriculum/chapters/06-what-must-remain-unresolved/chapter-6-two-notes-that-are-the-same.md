# What Must Remain Unresolved

## Chapter 6: Two Notes That Are the Same

Tavi's friend Sam also had a stuck circle with a sealed jar, and he wrote his note differently from Tavi's.

**Tavi's note:** `( ( x × 4 ) + 12 )`

**Sam's note:** `( 4 × ( x + 3 ) )`

"Mine is simpler," said Sam. "Yours is simpler," said Tavi. Which note is right?

### Step 1: Test both with numbers

They tried a few jars.

| x | Tavi's note | Sam's note |
|---|---|---|
| 0 | 12 | 12 |
| 1 | 16 | 16 |
| 2 | 20 | 20 |
| 5 | 32 | 32 |

The notes agree every time. Are they the same?

### Step 2: Find the reason

Numbers are evidence. For a reason, Tavi redrew Sam's note:

```
( 4 × ( x + 3 ) )
redraw  →  ( ( 4 × x ) + ( 4 × 3 ) )
pop ( 4 × 3 )  →  12
( ( 4 × x ) + 12 )
```

Four lots of x is the same as x taken four times, so ( 4 × x ) and ( x × 4 ) are the same. That gives Tavi's note. Because every redraw keeps the value, the two notes are the same for **every** jar.

They are the same note in different clothes.

### Step 3: Different clothes, different uses

If the notes mean the same, why would anyone prefer one?

- Sam's note ( 4 × ( x + 3 ) ) shows the **structure**: four lots of "the jar plus 3". It is shorter, and it tells you quickly that the answer is a multiple of 4.
- Tavi's note ( ( x × 4 ) + 12 ) shows the **pieces**: the part that depends on the jar, and the part that does not. It is easier to read off what the jar contributes.

The choice depends on what you need next. If Tavi is going to find x from a known total, as in chapter 5, either works. If she wants to say "the answer is 12 more than four jars", hers is clearer.

### Step 4: Two notes that only look the same

Compare these notes for two other circles.

**Note A:** `( x + x )`  **Note B:** `( x × x )`

At x = 2, both give 4. But at x = 3, A gives 6 and B gives 9.

| x | ( x + x ) | ( x × x ) |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 2 | 1 |
| 2 | 4 | 4 |
| 3 | 6 | 9 |

They agree at 0 and 2, and nowhere else. These notes are different. A test with only x = 2 would have missed it, which is the same lesson as the Two Boxes chapter.

### What did we keep?

Write the answers in your notebook.

- **What do two equal notes keep?** (The same value for every x.)
- **What can differ?** (The shape, which tells you different things.)

### What makes this trustworthy?

Two notes are the same when one can be redrawn into the other, and every redraw keeps the value. Testing a few numbers can show they are different, but only the redraw shows they are the same for all jars.

### Practice

1. Redraw ( 2 × ( x + 5 ) ) into the shape ( ( 2 × x ) + something ).

2. Is ( ( 2 × x ) + 5 ) the same note as ( 2 × ( x + 5 ) )? Test x = 0.

3. Is ( x + x ) the same note as ( 2 × x )? Give a reason.

4. Tavi's note is ( ( x × 4 ) + 12 ). Write another note for it that shows the structure "four lots of something".

5. For which values of x do ( x + x ) and ( x × x ) agree?

### Answers

1. ( ( 2 × x ) + ( 2 × 5 ) ) → ( ( 2 × x ) + 10 ).
2. No. At x = 0 the first gives 5 and the second gives 10.
3. Yes. Both mean two lots of x, so ( x + x ) and ( 2 × x ) are always equal.
4. ( 4 × ( x + 3 ) ), which is Sam's note.
5. They agree at **0 and 2** only.
