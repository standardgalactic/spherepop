# What Must Remain Unresolved

## Chapter 7: A Fraction Is a Note to Self

Tavi shared 17 marbles among 5 friends. Each friend got 3 marbles, and 2 were left over.

"What if I want to share the last 2 as well?" asked Tavi.

### Step 1: The circle that does not finish in whole numbers

Tavi wrote the problem in a circle:

```
( 17 ÷ 5 )
```

In whole numbers, the answer is 3 with 2 left over. She wrote it as

```
( 3 + ( 2 ÷ 5 ) )
```

The leftover circle ( 2 ÷ 5 ) holds only plain numbers, so it is ready. But 2 does not divide by 5 into a whole number. Tavi can leave it as a **fraction**, written 2/5, which means "2 shared among 5".

A fraction is a note to self. It says: *what is left is 2 shared among 5.* Nothing was lost, and nothing was pretended.

### Step 2: Popping to a decimal

Tavi could also pop the circle if decimals are allowed.

```
( 2 ÷ 5 )  →  0.4
```

So 17 ÷ 5 = 3.4. Check: 5 × 3.4 = 17. ✓

Here the decimal is exact, so the pop loses nothing.

### Step 3: When popping cannot finish

Now share 10 among 3 friends.

```
( 10 ÷ 3 )  →  ( 3 + ( 1 ÷ 3 ) )
```

Each friend gets 3, and 1 is left over. Try popping the leftover:

```
( 1 ÷ 3 )  →  0.3333...
```

The threes never stop. A pop cannot finish, because no ending decimal equals one third exactly. If Tavi writes 0.333 and multiplies by 3, she gets 0.999, not 1.

```
( 3 × 0.333 )  →  0.999
( 3 × ( 1 ÷ 3 ) )  →  1
```

The fraction 1/3 keeps the answer exact. The decimal is only an approximation. So the faithful note is the fraction, and Tavi should keep it unpopped when she needs an exact answer.

### Step 4: Exact or approximate?

This is a choice, like the ones in The Boundary of a Step.

- For a rough answer, a decimal like 3.33 is fine.
- For an exact answer, keep 3 and 1/3.

And when Tavi writes a decimal, she should say it is approximate, as in chapter 1 of A Useful Wrong Answer.

### What did we keep?

Write the answers in your notebook.

- **What does the fraction keep?** (The exact leftover, 1 shared among 3.)
- **What does the decimal 0.333 lose?** (A tiny piece, so 3 × 0.333 is not 1.)

### What makes this trustworthy?

A fraction is trustworthy because it says exactly what was left, and it can be popped later if a decimal is wanted. The check is to multiply back: 3 × ( 3 and 1/3 ) is 9 and 1, which is 10. ✓

### Practice

1. Write 11 ÷ 4 as a whole number plus a fraction. Pop the fraction to a decimal.

2. Write 10 ÷ 3 as a whole number plus a fraction. Can the fraction be popped exactly?

3. Check 3 and 1/3, times 3, equals 10.

4. Write 22 ÷ 7 as a whole number plus a fraction. Check by multiplying back.

5. When is it fine to write 3.33 for 10 ÷ 3?

### Answers

1. 11 ÷ 4 is 2 with 3 left over, so 2 + 3/4. The fraction pops to 0.75, so the answer is **2.75**.
2. 3 + 1/3. No: as a decimal it never ends, so keep **1/3**.
3. ( 3 × 3 ) + ( 3 × 1/3 ) = 9 + 1 = **10**. ✓
4. 7 goes into 22 three times with 1 left, so 3 + 1/7. Check: ( 7 × 3 ) + 1 = 22. ✓
5. When you only need a rough answer and say it is approximate. For an exact answer, keep the fraction.
