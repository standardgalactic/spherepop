# What Must Remain Unresolved

## Chapter 5: When the Total Is Known

Tavi's sister peeked at the receipt. "There are 20 marbles altogether," she said.

Now Tavi had an unknown jar and a known total. The circle was stuck at ( x + 12 ), and she also knew it equals 20.

```
( x + 12 )  =  20
```

### Step 1: Undo to find the jar

Tavi did not need to guess. She undid the +12, as in Reversing the Calculation.

```
20 − 12  →  8
```

So x = **8**. Check by putting 8 back in the circle: ( 8 + 12 ) pops to 20. ✓

What changed? The circle was stuck because it held x. A known total gave Tavi a way to work backward through the circle until x stood alone.

### Step 2: More than one step

A harder one. Tavi found 4 identical sealed jars, each holding x marbles, plus 3 bags of 4 marbles. The total is 40.

```
( ( x × 4 ) + 12 )  =  40
```

The last thing done to x was ×4, then +12. Tavi undid them in the opposite order, like socks and shoes.

- Undo the +12: 40 − 12 = 28.
- Undo the ×4: 28 ÷ 4 = 7.

So x = **7**. Check: ( ( 7 × 4 ) + 12 ) → ( 28 + 12 ) → 40. ✓

### Step 3: When the circles are arranged differently

Look at this arrangement, which has the same pieces in different circles:

```
( ( x + 3 ) × 4 )  =  40
```

The last thing done is the ×4, so undo that first.

- Undo ×4: 40 ÷ 4 = 10.
- Undo +3: 10 − 3 = 7.

So x = **7** again. Check: ( ( 7 + 3 ) × 4 ) → ( 10 × 4 ) → 40. ✓

Two different circles gave the same x, but only because the totals happened to line up. The circles are not the same question, as Tavi learned in chapter 1. They were set up to give the same answer, not to be the same.

### Step 4: Not always enough

Suppose the receipt said only "x + y = 15" for two jars. Tavi cannot find x and y from that. The total is known, but there are two unknowns in one circle, and many pairs fit.

A known total opens a circle only if there is **one** unknown inside it. With two, you need another clue.

### What did we keep?

Write the answers in your notebook.

- **What did the known total give Tavi?** (A way to work backward until x stood alone.)
- **What did she still need to check?** (That the x she found goes back into the original circle and gives the total.)

### What makes this trustworthy?

The check is putting x back into the original circle and popping. If it gives the known total, the answer fits. That check does not tell you whether another x could also fit. Here it could not, because each undo step has only one answer.

### Practice

1. Find x in ( x + 7 ) = 30.

2. Find x in ( ( x × 3 ) + 5 ) = 29.

3. Find x in ( ( x − 4 ) × 2 ) = 18.

4. Check your answer to problem 3 by putting it back.

5. The receipt says ( x + y ) = 20. Can Tavi find x? What would help?

### Answers

1. 30 − 7 = **23**. Check: 23 + 7 = 30. ✓
2. Undo +5: 29 − 5 = 24. Undo ×3: 24 ÷ 3 = **8**. Check: 8 × 3 + 5 = 29. ✓
3. Undo ×2: 18 ÷ 2 = 9. Undo −4: 9 + 4 = **13**.
4. ( ( 13 − 4 ) × 2 ) → ( 9 × 2 ) → 18. ✓
5. No. Many pairs fit, such as 5 and 15 or 10 and 10. A clue about x, or about y, would help.
