# Solving by Changing the Question

## Chapter 3: Slide Both Numbers

Pia noticed that her bus fare and her brother's bus fare were different, but each year both fares went up by the same amount, so the *gap* between them stayed the same. The gap did not care about the shift.

That gave Pia an idea for subtraction.

### Step 1: Slide both numbers by the same amount

Take **83 − 29**. Imagine both numbers on a number line. What if you slide both of them one step to the right?

```
( 83 − 29 )  →  54
( 84 − 30 )  →  54
```

The gap between them did not change. And 84 − 30 is much easier, because 30 is a round number.

This is a redraw that changes the question without changing the answer:

```
( 83 − 29 )
redraw  →  ( 84 − 30 )
pop  →  54
```

More examples:

- **612 − 498.** Slide both up by 2: 614 − 500 = **114**.
- **1,003 − 997.** Slide both up by 3: 1,006 − 1,000 = **6**.
- **91 − 48.** Slide both up by 2: 93 − 50 = **43**.

### Step 2: Why it works

Subtraction asks, "how far apart?" If you move both numbers the same distance in the same direction, the distance between them stays exactly the same.

You can also *undo* the slide: slide both back. A change that can be undone, as in chapter 2, keeps the answers.

### Step 3: A warning, and a new move for sums

Sliding both numbers does **not** work for adding.

```
( 29 + 83 )  →  112
( 30 + 84 )  →  114
```

The answers are different. Adding does not ask about the gap, it asks about the total, and sliding both numbers up adds the slide twice.

But there is a similar move for sums: **move one number up and the other down by the same amount**.

```
( 29 + 83 )
redraw  →  ( 30 + 82 )
pop  →  112
```

What one number gained, the other lost, so the total is the same. Another example: 198 + 47 → ( 200 + 45 ) → **245**.

So the rule depends on what the question asks.

- A **difference** stays the same when both numbers slide **together**.
- A **sum** stays the same when one slides **up** and the other slides **down**.

### What did we keep?

Write the answers in your notebook.

- **What does sliding both numbers keep for subtraction?** (The gap between them, which is the answer.)
- **What does it lose?** (The numbers themselves. 84 − 30 no longer mentions 83 and 29.)

### What makes this trustworthy?

A change is trustworthy when you know what it keeps. Subtraction keeps the gap, so a slide together is safe. A sum keeps the total, so a swap of up and down is safe. The wrong move for the wrong question, like sliding both numbers for a sum, gives a wrong answer even though it looks similar.

As in chapter 1, always take the answer home. Check 54 in the original: 83 − 29 = 54, and 29 + 54 = 83. ✓

### Practice

1. Find 502 − 297 by sliding both numbers up by 3.

2. Find 91 − 48 by sliding both up by 2. Check your answer by adding 48 to it.

3. Find 6,001 − 2,998.

4. Find 396 + 127 by moving 4 from one number to the other.

5. Dani says: "52 + 38 is the same as 54 + 40, since I slid both up by 2." What is wrong with that?

6. Redraw ( 71 − 39 ) by sliding both numbers and pop it.

### Answers

1. ( 502 − 297 ) → ( 505 − 300 ) → **205**.
2. ( 93 − 50 ) pops to **43**. Check: 43 + 48 = 91. ✓
3. Slide both up by 2: ( 6,003 − 3,000 ) → **3,003**.
4. Move 4 from 127 to 396: ( 400 + 123 ) → **523**.
5. Sliding both numbers adds the slide twice to a sum. 52 + 38 = 90, but 54 + 40 = 94. For a sum, move one up and the other down: ( 54 + 36 ) → 90.
6. Slide both up by 1: ( 72 − 40 ) → **32**.
