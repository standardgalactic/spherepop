# Solving by Changing the Question

## Chapter 2: The Change That Added Too Much

Pia loved changing questions. One day she tried a new move on the equation **x + 1 = 5**.

"I'll multiply both sides by 0," she said. "It will be 0 on the left and 0 on the right."

```
( x + 1 ) × 0  =  5 × 0
0  =  0
```

"Zero equals zero," said Pia. "That is true! So the answer is... every number?"

Her older brother laughed. "Check it in the original."

### Step 1: Take the answer home

Pia picked x = 7 and took it back to the original question:

```
x + 1 = 5   with x = 7:   7 + 1 = 8,  and 8 is not 5.
```

So x = 7 is **not** an answer to the original. But it *was* an answer to the new question ( 0 = 0 is true for every x ). The new question had added answers that the old one did not have.

This is a cousin of the lesson from chapter 1. There, a change could lose something. Here, a change can **gain** something it should not.

### Step 2: Why did multiplying by 0 add answers?

When you multiply both sides by 0, you throw away the information on both sides. Everything turns into 0. Before the change, the equation was fussy: only x = 4 worked. After, nothing is fussy: every x works.

Multiplying both sides by 2 is different:

```
( x + 1 ) × 2  =  5 × 2
2x + 2  =  10
```

You can also *undo* it, by dividing both sides by 2, and you are back at x + 1 = 5. Because the change can be undone, no answers were added or lost.

That gives a rule:

**A change keeps the answers if you can undo it.**

Multiplying by 2 can be undone (divide by 2). Adding 3 to both sides can be undone (subtract 3). Multiplying by 0 cannot be undone, because every number times 0 is 0. You met this in Reversing the Calculation: a button with no undo forgets where it came from.

### Step 3: A change that can lose an answer

Here is a puzzle: **x × 3 = x × 5**.

Pia first tried dividing both sides by x:

```
3  =  5
```

"That is false," she said. "So there are no answers."

But then she tried x = 0 in the original:

```
0 × 3 = 0   and   0 × 5 = 0
```

Both sides are 0! So x = 0 **is** an answer. The new question 3 = 5 had lost it.

Why? Dividing by x cannot be undone when x is 0. You cannot divide by 0. So the change was only safe for starting values other than 0. Pia learned to say: "I divided by x, so I need to check x = 0 separately."

### Step 4: In circles

Here is Step 3 as a picture. Each side is a circle with a mystery x inside.

```
( x × 3 )  =  ( x × 5 )
```

Neither circle is ready, since each holds x. Pia can test a value by dropping it in, which makes the circles ready:

```
x = 0:   ( 0 × 3 ) = ( 0 × 5 )   pop both  →  0 = 0   ✓
x = 2:   ( 2 × 3 ) = ( 2 × 5 )   pop both  →  6 = 10  ✗
```

Dropping a value in and popping is the test that never changes the question. It always checks against the original.

### What did we keep?

Write the answers in your notebook.

- **What did multiplying by 2 keep?** (Exactly the same answers.)
- **What did multiplying by 0 do?** (It added answers that were not in the original.)
- **What did dividing by x do?** (It lost the answer x = 0.)

### What makes this trustworthy?

A change of question is trustworthy when you can undo it, because then it keeps exactly the same answers. If it cannot be undone, then either it added answers, or it lost some, and you have to check.

The check that always works is to take the answer home, as Pia's brother said. That catches **added** answers. It does not catch **lost** answers, because you cannot test a number you never found. To catch lost answers, ask: "Is there any value where my change would not be allowed?"

### Practice

1. Solve x + 2 = 9 by adding 3 to both sides, then solving. Can the change be undone?

2. Pia changes x + 2 = 9 by multiplying both sides by 0. Which numbers now make the new question true? Which of them are answers to the original?

3. Check x = 0 and x = 4 in the puzzle x × 6 = x × 6. What do you notice?

4. Pia divides both sides of x × 2 = x × 7 by x. What does she get? Is there an answer she lost?

5. A button doubles a number. Another button multiplies it by 0. Which one could you use as a safe change of question? Why?

### Answers

1. Adding 3 gives x + 5 = 12. Then x = 7. Yes, you can undo it by subtracting 3, so the answers are the same: **x = 7**.
2. The new question is 0 = 0, which is true for **every** number. Only x = 7 is an answer to the original.
3. Both x = 0 and x = 4 work: 0 × 6 = 0 × 6 and 4 × 6 = 4 × 6. Every number works, since both sides are the same.
4. She gets 2 = 7, which is false. She lost x = 0, since 0 × 2 = 0 and 0 × 7 = 0. So **x = 0** is an answer.
5. The doubling button, because it can be undone by halving. The ×0 button cannot be undone, so it might add answers.
