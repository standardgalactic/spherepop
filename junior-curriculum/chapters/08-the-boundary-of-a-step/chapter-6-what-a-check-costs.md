# The Boundary of a Step

## Chapter 6: What a Check Costs

Sade had worked out 23 × 47 and got 1,081. Before she wrote it on the bill, she wanted to check it. But checks cost steps too.

### Step 1: Three checks and their cost

**Check 1, the last digit.** The last digits are 3 and 7, and 3 × 7 = 21, so the answer should end in 1.

```
( 3 × 7 )  →  21
```

1 pop. 1,081 ends in 1. ✓

**Check 2, the size.** The answer must lie between two easy products.

```
( 20 × 40 )  →  800
( 25 × 50 )  →  1,250
```

2 pops. 1,081 is between 800 and 1,250. ✓

**Check 3, a second route.** Split 47 as 40 + 7.

```
( ( 23 × 40 ) + ( 23 × 7 ) )
pop  →  ( 920 + 161 )
pop  →  1,081
```

3 pops. It agrees. ✓

### Step 2: Cost against what each check can catch

| Check | Cost | What it can catch |
|---|---|---|
| Last digit | 1 pop | slips in the ones digit |
| Size | 2 pops | answers far too big or too small |
| Second route | 3 pops | almost any slip |

The cheapest check catches the fewest mistakes. The most expensive one catches the most, but it costs about as much as doing the whole problem again.

A sensible plan, which Sade followed, is to **start cheap**. Last digit first. If it fails, the answer is wrong and she saves the other steps. If it passes, she tries the size check. And she keeps the second route for answers that matter.

### Step 3: What counts as a step in a check

Remember from chapter 5 that a step count leaves out the ideas. The last-digit check needs an idea too: that the ones digit of a product only depends on the ones digits. Once you know it, it costs 1 pop.

So a check has two prices:

- **The pops** it uses each time.
- **The idea** you need to know first, which you pay once.

### Step 4: When a check is not worth it

If the bill is for a few cents and an error would not matter, even the last-digit check may not be worth it. If the bill is for a thousand dollars, the second route is a bargain.

The right amount of checking depends on how much a mistake would cost. That is a decision about the job, not a rule of arithmetic.

### What makes this trustworthy?

A check is trustworthy when you know what it can catch and what it cannot. A passed last-digit check says nothing about the tens. As in A Useful Wrong Answer, a passed check never proves an answer right, and a failed check proves it wrong.

### Practice

1. For 38 × 52 = 1,976, do the last-digit check. How many pops?

2. Do a size check for 38 × 52 using 38 × 50 and 40 × 52. Does 1,976 pass?

3. Do a second route for 38 × 52 by splitting 52 as 50 + 2. How many pops?

4. Put the three checks in order from cheapest to most expensive.

5. Sade's answer fails the last-digit check. Should she do the size check next? Why or why not?

### Answers

1. 8 × 2 = 16, so the answer should end in 6. 1,976 ends in 6. ✓ **1 pop**.
2. 38 × 50 = 1,900 is below the answer because 52 is more than 50, and 40 × 52 = 2,080 is above it because 38 is less than 40. 1,976 is between them. ✓ **2 pops**.
3. ( ( 38 × 50 ) + ( 38 × 2 ) ) → ( 1,900 + 76 ) → **1,976**. **3 pops**. ✓
4. Last digit (1 pop), size (2 pops), second route (3 pops).
5. No. A failed check already proves the answer is wrong. She should redo the problem.
