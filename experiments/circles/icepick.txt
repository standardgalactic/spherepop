# Choose the Next Pop

An interactive companion to *An Introduction to SpherePOP: Nested Circles,
Typed Operators, and Reduction*, chapters 1–7. Open
[`index.html`](index.html) through a static HTTP server. No package install,
external assets, build step, or service is needed.

From the repository root:

```sh
python3 -m http.server 8000
```

Visit <http://localhost:8000/experiments/circles/>. Select an eligible circle
and pop it, reduce a simultaneous frontier, undo an action, substitute an
integer for a free symbol, or compare leftmost, rightmost and parallel
strategies. The JSON editor accepts typed terms, never executable Python or
JavaScript. Export preserves exact input and output terms for every action.

The presets cover explicit grouping, disjoint redexes, balanced parallel
reduction, partial evaluation, inert terms, power towers, immutable images,
recolouring, clockwise rotation, composition and domain restrictions.
J/K selects ready circles, Enter pops, P performs one simultaneous round,
U undoes, and R resets. Buttons and circle selection also support keyboard
focus. Editing fields do not trigger these shortcuts. The layout supports
small screens and uses no animation or audio.

## What the experiment establishes

`engine.mjs` implements pure value-returning operators using exact BigInt
arithmetic. A normal form may still be an inert circle: unknown operators,
wrong arities, unsupplied symbols, sort mismatches and inadmissible operand
tuples do not become successful values. The resource budget is reported
separately; an admissible operation can exceed browser limits.

Each ordinary pop removes exactly one circle. The simultaneous operation
captures all ready positions before modifying the term, so newly enabled
parents wait until the next round. Left/right/parallel comparisons start
from the current expression. Bounded exploration deduplicates identical
terms, counts distinct states and transitions, and explicitly reports when
its state budget prevents exhaustive exploration. It does not count all
paths and is not a proof of general confluence. Parallel rounds measure
logical dependency depth, not actual parallel execution or wall-clock time.

Input is limited to 255 terms, depth 24, 100 KB of JSON, and rectangular
images up to 16 × 16. Arithmetic has a 20,000-decimal-digit result limit
and a conservative exponent budget. The book's five-two tower, 2**65536,
fits. Display abbreviates large numbers while exported traces retain them.
The total-pops metric includes every recorded pop, including ones taken
before a substitution. The parallel-rounds metric counts only explicitly
requested simultaneous rounds, not mixed sequential actions.

This core experiment does not implement the symbolic rewriting extension
of chapter 8, lambda binding, mutable instruction bubbles, or the canonical
event-history kernel in `experiments/flat`. In particular, an inert circle
is not a REFUSE event and a pop here is not a historical commitment event.
The existing `reduction-engine/` remains a separate teaching model.

## Verification

With Node.js 20+ and Python 3.10+ available, run from the repository root:

```sh
node experiments/circles/test.mjs
```

`oracle.py` explicitly loads `spherepop-book-source/spherepop.py` by path,
avoiding collisions with older packages named `spherepop`. Presets,
deterministically generated arithmetic and symbolic terms, substitutions,
invalid operator applications, images and a large integer are compared
against the book for their first reduction, normal form, size and pop count.
Independent checks exercise disjoint-pop diamonds, size decrease, strategy
agreement, parallel-frontier timing, image orientation and persistence,
exploration cutoffs and resource/input limits.

The dedicated `circle-laboratory.yml` workflow checks changes to this
experiment, the book interpreter, or its own definition. It uses sparse
checkout and read-only permissions. The existing C/cross-language workflow
and its conformance report are unaffected.

function message(text = "") {

const pathName = (p) => (p.length ? p.map((i) => i + 1).join(".") : "root");
function load(term, meta) {
  initial = term;
  current = term;
  example = meta;
  selected = 0;
  actions = [];
  undo = [];
  comparison = "";
  $("source").value = JSON.stringify(term, null, 2);
  message();
  render();
}
function commit(term, label, pops = 0, rounds = 0, paths = []) {
  undo.push({ current, actions: [...actions], selected, comparison });
  actions.push({
    action: label,
    paths,
    input: current,
    output: term,
    pops,
    parallelRounds: rounds,
  });
  current = term;
  selected = 0;
  comparison = "";
  message();
  render();
}
function safely(fn) {
  try {
    fn();
  } catch (error) {
    message(error.message);
  }
}
function choosePop() {
  safely(() => {
    const r = ready(current)[selected];
    if (r)
      commit(
        pop(current, r.path),
        `Pop ${r.term.op} at ${pathName(r.path)}`,
        1,
        0,
        [r.path],
      );
  });
}
function oneRound() {
  safely(() => {
    const frontier = ready(current);
    if (!frontier.length) return;
    const next = parallel(current);
    commit(
      next.term,
      `Parallel round: ${next.pops} pops`,
      next.pops,
      1,
      frontier.map((r) => r.path),
    );
  });
}
function back() {
  const state = undo.pop();
  if (state) {
    ({ current, actions, selected, comparison } = state);
    message();
    render();
  }
}

function draw(t, path = []) {
  if (t.kind === "circle") {

    box.append(el("span", t.op, "operator"));
    const args = el("div", undefined, "operands");
    t.args.forEach((a, i) => args.append(draw(a, [...path, i])));
    box.append(args);
    box.title = reason(t) ?? `Ready: ${t.op}. Select, then pop.`;
    if (index >= 0) {
      box.tabIndex = 0;
      box.setAttribute("role", "button");
      box.setAttribute(
        "aria-label",
        `Select ready ${t.op} at ${pathName(path)}`,
      );
      box.setAttribute("aria-pressed", String(index === selected));
      box.addEventListener("click", (event) => {
        event.stopPropagation();
        selected = index;
        render();
      });
      box.addEventListener("keydown", (event) => {
        if (event.key === " " || event.key === "Enter") {
          event.preventDefault();
          event.stopPropagation();
          selected = index;
          render();
          $("pop").focus();

      });
    }
    return box;
  }
  if (t.kind === "image") {
    const grid = el("div", undefined, "pixel-image");
    grid.style.gridTemplateColumns = `repeat(${t.rows[0].length},1fr)`;
    grid.setAttribute("role", "img");

      `Image: ${t.rows.map((r) => r.join(" ")).join("; ")}`,
    );
    t.rows.flat().forEach((p) => {
      const cell = el("span", undefined, "pixel");
      cell.style.background =
        p === "." ? "transparent" : (palette[p] ?? "#d4bd91");
      cell.title = p === "." ? "transparent" : p;
      grid.append(cell);
    });
    return grid;
  }
  const atom = el(
    "span",
    show(t),
    `atom${t.kind === "sym" ? " symbol" : ""}${t.kind === "num" && t.value.length > 70 ? " long-number" : ""}`,
  );
  if (t.kind === "color") atom.style.color = palette[t.name] ?? "#d4bd91";

// The pure, many-sorted fragment of An Introduction to SpherePOP, chapters 1–7.
// BigInt keeps numerical values integral, including the book's power towers.
export const num = (value) => ({ kind: "num", value: String(BigInt(value)) });
export const sym = (name) => ({ kind: "sym", name });
export const color = (name) => ({ kind: "color", name });
export const image = (rows) => ({ kind: "image", rows });
export const circle = (op, ...args) => ({ kind: "circle", op, args });
const signatures = {
  add: ["num", "num"],
  sub: ["num", "num"],
  mul: ["num", "num"],
  pow: ["num", "num"],
  rotate: ["image", "num"],
  recolor: ["image", "color"],
  beside: ["image", "image"],
};
export const size = (t) =>
  t.kind === "circle" ? 1 + t.args.reduce((n, a) => n + size(a), 0) : 0;
export const depth = (t) =>
  t.kind === "circle" ? 1 + Math.max(0, ...t.args.map(depth)) : 0;
export const key = (t) => JSON.stringify(t);
export const equal = (a, b) => key(a) === key(b);
export function show(t) {
  if (t.kind === "circle")
    return `<${t.op}${t.args.length ? " " : ""}${t.args.map(show).join(" ")}>`;
  if (t.kind === "num")
    return t.value.length > 70
      ? `${t.value.slice(0, 28)}… (${t.value.length} digits)`
      : t.value;
  if (t.kind === "image")
    return `image(${t.rows.map((r) => r.join("")).join("/")})`;
  return t.name;
}
export function validate(t, level = 0, counter = { n: 0 }) {
  if (++counter.n > 255 || level > 24)
    throw Error("Use at most 255 terms and nesting depth 24.");
  if (!t || typeof t !== "object")
    throw Error("A term must be a typed object.");
  if (t.kind === "num") {
    if (typeof t.value !== "string" || !/^-?\d{1,20000}$/.test(t.value))
      throw Error(
        "Numbers must be decimal integer strings (at most 20,000 digits).",
      );
    return num(t.value);
  }
  if (t.kind === "sym" || t.kind === "color") {
    if (
      typeof t.name !== "string" ||
      !/^[A-Za-z][A-Za-z0-9_-]{0,31}$/.test(t.name)
    )
      throw Error(
        "Names must contain letters, digits, underscores or hyphens.",
      );
    return { kind: t.kind, name: t.name };
  }
  if (t.kind === "image") {
    if (
      !Array.isArray(t.rows) ||
      !t.rows.length ||
      t.rows.length > 16 ||
      !Array.isArray(t.rows[0]) ||
      !t.rows[0].length ||
      t.rows[0].length > 16 ||
      !t.rows.every(
        (r) =>
          Array.isArray(r) &&
          r.length === t.rows[0].length &&
          r.every(
            (p) =>
              typeof p === "string" &&
              /^(\.|[A-Za-z][A-Za-z0-9_-]{0,31})$/.test(p),
          ),
      )
    )
      throw Error(
        "Images must be rectangular, nonempty grids no larger than 16 × 16.",
      );
    return image(t.rows.map((r) => [...r]));
  }
  if (t.kind === "circle") {
    if (
      typeof t.op !== "string" ||
      !/^[A-Za-z][A-Za-z0-9_-]{0,31}$/.test(t.op) ||
      !Array.isArray(t.args) ||
      t.args.length > 8
    )
      throw Error("Invalid circle operator or operands.");
    return circle(t.op, ...t.args.map((a) => validate(a, level + 1, counter)));
  }
  throw Error("Unknown term kind.");
}
export function reason(t) {
  if (t.kind !== "circle") return "Already a value.";
  const sig = signatures[t.op];
  if (!sig) return `Unknown operator: ${t.op}.`;
  if (t.args.length !== sig.length)
    return `${t.op} needs ${sig.length} operands.`;
  if (t.args.some((a) => a.kind === "circle"))
    return "Waiting for an inner circle.";
  if (t.args.some((a, i) => a.kind !== sig[i]))
    return `Requires ${sig.join(" × ")}; symbols need substitution.`;
  if (t.op === "pow" && BigInt(t.args[1].value) < 0n)
    return "Negative exponents are outside the integer carrier.";
  if (t.op === "rotate" && BigInt(t.args[1].value) % 90n !== 0n)
    return "Rotation requires a multiple of 90 degrees.";
  if (t.op === "beside" && t.args[0].rows.length !== t.args[1].rows.length)
    return "Images must have equal heights.";
  return null;
}
export class BudgetError extends Error {}
export function evaluate(t) {
  const why = reason(t);
  if (why) throw Error(why);
  const [a, b] = t.args;
  if (["add", "sub", "mul", "pow"].includes(t.op)) {
    const x = BigInt(a.value),
      y = BigInt(b.value);
    let v;
    if (t.op === "add") v = x + y;
    if (t.op === "sub") v = x - y;
    if (t.op === "mul") v = x * y;
    if (t.op === "pow") {
      // A resource boundary, never a semantic refusal. Allow the five-two tower.
      if (
        y > 100000n ||
        (x !== 0n &&
          x !== 1n &&
          x !== -1n &&
          BigInt((x < 0n ? -x : x).toString(2).length) * y > 140000n)
      )
        throw new BudgetError(
          "Power exceeds the browser arithmetic budget; the circle is admissible but has not been evaluated.",
        );
      v = x ** y;
    }
    if (v.toString().length > 20000)
      throw new BudgetError("Result exceeds the 20,000-digit display budget.");
    return num(v);
  }
  if (t.op === "recolor")
    return image(a.rows.map((r) => r.map((p) => (p === "." ? "." : b.name))));
  if (t.op === "beside") {
    if (a.rows[0].length + b.rows[0].length > 16)
      throw new BudgetError("Result exceeds the 16-column image budget.");
    return image(a.rows.map((r, i) => [...r, ...b.rows[i]]));
  }
  let rows = a.rows.map((r) => [...r]),
    turns = Number((((BigInt(b.value) / 90n) % 4n) + 4n) % 4n);
  while (turns--) rows = rows[0].map((_, i) => rows.map((r) => r[i]).reverse());
  return image(rows);
}
export function ready(t, path = []) {
  if (t.kind !== "circle") return [];
  const children = t.args.flatMap((a, i) => ready(a, [...path, i]));
  return reason(t) === null ? [...children, { path, term: t }] : children;
}
export function at(t, path) {
  return path.reduce((a, i) => a.args[i], t);
}
export function replace(t, path, value) {
  if (!path.length) return value;
  const [i, ...rest] = path;
  return circle(
    t.op,
    ...t.args.map((a, j) => (j === i ? replace(a, rest, value) : a)),
  );
}
export function pop(t, path) {
  return replace(t, path, evaluate(at(t, path)));
}
export function parallel(t) {
  // Capture the frontier before reducing: parents newly enabled wait one round.
  const frontier = ready(t);
  return {
    term: frontier.reduce((out, r) => pop(out, r.path), t),
    pops: frontier.length,
  };
}
export function substitute(t, env) {
  if (t.kind === "sym") return env[t.name] ?? t;
  return t.kind === "circle"
    ? circle(t.op, ...t.args.map((a) => substitute(a, env)))
    : t;
}
export function symbols(t) {
  return [
    ...new Set(
      t.kind === "sym"
        ? [t.name]
        : t.kind === "circle"
          ? t.args.flatMap(symbols)
          : [],
    ),
  ].sort();
}
export function normalize(t, strategy = "left") {
  let pops = 0,
    rounds = 0;
  while (ready(t).length) {
    if (strategy === "parallel") {
      const next = parallel(t);
      t = next.term;
      pops += next.pops;
    } else {
      const rs = ready(t);
      t = pop(t, rs[strategy === "right" ? rs.length - 1 : 0].path);
      pops++;
    }
    rounds++;
    if (rounds > 255) throw new BudgetError("Reduction budget reached.");
  }
  return { term: t, pops, rounds };
}
export function explore(t, limit = 1200) {
  const queue = [t],
    seen = new Set([key(t)]),
    normalForms = new Map();
  let edges = 0;
  for (let i = 0; i < queue.length; i++) {
    const rs = ready(queue[i]);
    if (!rs.length) normalForms.set(key(queue[i]), queue[i]);
    for (const r of rs) {
      const next = pop(queue[i], r.path);
      edges++;
      if (!seen.has(key(next))) {
        if (seen.size >= limit)
          return {
            complete: false,
            states: seen.size,
            edges,
            normalForms: [...normalForms.values()],
          };
        seen.add(key(next));
        queue.push(next);
      }
    }
  }
  return {
    complete: true,
    states: seen.size,
    edges,
    normalForms: [...normalForms.values()],
  };
}

import importlib.util

from pathlib import Path
import sys

SOURCE = Path(__file__).resolve().parents[2] / 'spherepop-book-source' / 'spherepop.py'
spec = importlib.util.spec_from_file_location('spherepop_book_reference', SOURCE)
book = importlib.util.module_from_spec(spec)
sys.modules[spec.name] = book
spec.loader.exec_module(book)
if hasattr(sys, 'set_int_max_str_digits'):
    sys.set_int_max_str_digits(0)


def decode(term):
    kind = term['kind']
    if kind == 'num':
        return int(term['value'])
    if kind == 'sym':
        return book.Sym(term['name'])
    if kind == 'color':
        return book.Color(term['name'])
    if kind == 'image':
        return book.Image(tuple(tuple(row) for row in term['rows']))
    return book.Circle(term['op'], tuple(decode(a) for a in term['args']))


def encode(term):
    if isinstance(term, int):
        return {'kind': 'num', 'value': str(term)}
    if isinstance(term, book.Sym):
        return {'kind': 'sym', 'name': term.name}
    if isinstance(term, book.Color):
        return {'kind': 'color', 'name': term.name}
    if isinstance(term, book.Image):
        return {'kind': 'image', 'rows': [list(row) for row in term.rows]}
    return {'kind': 'circle', 'op': term.op, 'args': [encode(a) for a in term.args]}


def run(case):
    term = decode(case['term'])
    if 'env' in case:
        term = book.substitute(term, {k: decode(v) for k, v in case['env'].items()})
    result, pops = book.normalize(term)
    step = book.step(term)
    return {'term': encode(result), 'pops': pops, 'size': book.size(term),
            'step': None if step is None else encode(step)}


if __name__ == '__main__':
    print(json.dumps([run(case) for case in json.load(sys.stdin)]))

function freeze(t) {
  Object.freeze(t);
  if (t.kind === "circle") t.args.forEach(freeze);
  for (const v of Object.values(t))
    if (Array.isArray(v)) {
      Object.freeze(v);
      v.filter(Array.isArray).forEach(Object.freeze);
    }
  return t;
}
